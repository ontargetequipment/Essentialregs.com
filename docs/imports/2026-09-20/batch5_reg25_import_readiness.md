# Reg 25 — import readiness report (September 20, 2026)

## Verdict: READY WITH NOTES

Regulation Number 25 parses to **993 rows** with 0 orphans, 0 duplicate ids (one documented source-text duplicate label merged, as Reg 7 does), 0 repeated-text flags, 0 dead cross-reference targets, 0 page-furniture leaks, and every one of the regulation's **19 tables** (5 captioned, 14 uncaptioned — including the two-page Appendix E equivalency table and the eleven-page Part C tracking table) rendered as a `doc-table` with every cell verified against the source text.
